# Código de conducta

Sun quiere ser un espacio tranquilo para quien participe. Este acuerdo es breve a propósito: el proyecto lo mantiene una sola persona.

## Compromiso

Quienes colaboran se tratan con cortesía. Las preguntas, los desacuerdos y las correcciones de buena fe son bienvenidos.

## Se espera

- Hablar con respeto, también cuando hay desacuerdo.
- Centrarse en el trabajo y en las ideas.
- Aceptar la crítica concreta.
- Respetar el tiempo de quien mantiene el proyecto.

## No se acepta

- Insultos, acoso o ataques personales.
- Publicar información privada de otra persona sin su permiso.
- Spam o contenido ajeno al proyecto.

## Cómo avisar de un problema

Escribe a Luis Alfredo Caicedo Vega por GitHub, en el usuario `lacvHacks`, y describe lo ocurrido con hechos. El aviso se trata con discreción. Quien rompa este acuerdo puede ver cerrado su issue o su pull request.
