# Cómo contribuir a Sun

Gracias por querer colaborar. Sun es un proyecto personal pequeño y las contribuciones se revisan con calma.

## Antes de abrir un cambio

- Mira los issues y los pull requests abiertos para no repetir trabajo.
- Si el cambio es grande o cambia el rumbo del proyecto, coméntalo antes en un issue.

## Pasos

1. Haz un fork y crea una rama a partir de `main`.
2. Limita el cambio a una sola idea.
3. Escribe un mensaje de commit que diga qué haces y por qué.
4. Abre un pull request contra `main`.
5. En la descripción, explica el cambio y cómo se puede comprobar.

## Estilo

- La documentación se escribe en español, con frases cortas.
- No subas secretos, tokens ni datos personales de otras personas.
- Si más adelante añades código, indica cómo ejecutarlo o probarlo.

## Revisión

Luis Alfredo Caicedo Vega revisa los pull requests cuando puede. Puede pedir ajustes antes de fusionar. Un pull request pequeño y claro se revisa antes que uno amplio.
