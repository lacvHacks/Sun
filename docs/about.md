# Acerca de Sun

Sun es un proyecto personal de Luis Alfredo Caicedo Vega (`lacvHacks`). El repositorio está en una fase inicial: guarda el nombre del proyecto y su documentación básica mientras se decide el primer alcance útil.

## Para qué existe

Sirve como espacio propio para probar ideas pequeñas, dejarlas por escrito y, más adelante, publicar código corto que se pueda leer y ejecutar sin ceremonia.

## Quién lo mantiene

Lo mantiene una sola persona, en su tiempo libre. Las respuestas y las fusiones llegan cuando hay hueco, no según un calendario fijo.

## Nombre

El proyecto se llama Sun, tal como aparece en el título del README.
