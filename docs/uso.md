# Uso

Sun todavía no ofrece un programa que instalar. Esta nota describe cómo orientarse en el repositorio hoy y qué cambiará cuando haya código.

## Estado actual

El proyecto está en documentación inicial. Clonar el repositorio basta para leerlo:

```bash
git clone https://github.com/lacvHacks/Sun.git
cd Sun
```

No hay dependencias, comandos de build ni variables de entorno.

## Qué leer primero

- El README, para el nombre del proyecto.
- `docs/about.md`, para saber de qué trata.
- `docs/roadmap.md`, para ver hacia dónde va.
- `docs/faq.md`, para las dudas más cortas.

## Cuando haya código

La primera versión ejecutable deberá indicar aquí, en pocas líneas:

1. qué hace;
2. qué hay que tener instalado;
3. el comando para probarlo.

Hasta entonces, no hace falta configurar nada.
