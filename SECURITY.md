# Política de seguridad

Sun es un proyecto personal pequeño. Si encuentras un problema de seguridad, avisa en privado antes de hacerlo público.

## Cómo reportarlo

No abras un issue público con los detalles del fallo. Escribe al autor por GitHub (`lacvHacks`) e incluye:

- qué parte del proyecto afecta;
- los pasos para reproducirlo, si los conoces;
- el impacto que observaste.

No incluyas datos de otras personas ni un exploit listo para usar.

## Qué puedes esperar

El autor lee los avisos cuando puede y responde con el siguiente paso. No hay un programa de recompensas económicas.

## Versiones cubiertas

Solo se mantiene la rama `main`.
